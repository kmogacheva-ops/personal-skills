# Персональные навыки Codex

Переиспользуемые инструкции без клиентских данных и внутренних прайсов.

## Проверка КП перед отправкой

`skills/parkskazka-proposal-review` — проверка готового КП «Сказки» или ВАУПОВОД по брифу, прайсу и договоренностям: состав услуг, расчеты, подтверждение обещаний и готовность клиентской версии.

Пример запроса: «Проверь это КП перед отправкой. Прилагаю бриф, прайс и переписку; выдели ошибки и дай исправленные формулировки».

## Установка

Скопируйте папку `skills/parkskazka-proposal-review` в `$CODEX_HOME/skills` (по умолчанию `~/.codex/skills`). Навык должен находиться в отдельной папке с файлом `SKILL.md`. Реальные документы передавайте только при выполнении задачи; не добавляйте их в репозиторий навыков.
